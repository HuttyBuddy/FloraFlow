## 2024-05-18 - Nested Loops Bottleneck in CompanionSynergyCard.kt
**Learning:** O(N^2) loops over grid data can become severely unoptimized when repeating similar bounds/distance checking, particularly using expensive `sqrt()` functions that aren't necessary for integer-bound distances. Combining iterations and using distance-squared bounds with fast-failing checks produces significant performance improvements.
**Action:** When working on grid layouts or spatial mapping in Kotlin/Compose, always prefer single-pass loops calculating all combinations, and use squared-distance (`dx * dx + dy * dy`) rather than `sqrt()` for simple range checks.
