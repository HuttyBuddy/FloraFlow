## 2026-06-12 - Empty States Need CTAs
**Learning:** Users can feel stuck when encountering empty states (like 'no logs' or 'no layouts') if only descriptive text is provided without a clear next step. Explanatory text is good, but without inline action, they must navigate the UI to find where to initiate the described action.
**Action:** Always pair empty state descriptive text with an immediate, prominent inline Call-To-Action (CTA) button that triggers the relevant creation flow.
