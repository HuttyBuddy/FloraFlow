# Short-Form Video — Hook Formulas & Scripting Templates

Extended reference for TikTok, Instagram Reels, and YouTube Shorts scripting.

## Hook Formulas (First 1-3 Seconds)

### Visual Hooks
- Start mid-action (already doing the thing, not setting up)
- Show the end result first, then "here's how"
- Unexpected object/setting juxtaposition
- Fast zoom or whip-pan into the subject

### Verbal Hooks
- "Wait, you're doing [common task] wrong."
- "Nobody told me this about [topic] until [time]."
- "Here's what [X] doesn't want you to know."
- "I tested [N] [things] so you don't have to."
- "This took me [short time] and [impressive result]."

### Text Overlay Hooks
- A single bold question: "Why does this work?"
- A number: "3 mistakes killing your [thing]"
- A claim that creates tension: "This is the opposite of what everyone says"

**Combine all three** — visual + verbal + text overlay should reinforce the same idea in the first second.

## Full Scripting Templates

### Problem-Solution Script
```
[0-3s] HOOK (on screen + spoken):
"If your [thing] keeps [problem], it's probably this."

[3-10s] AGITATE:
"Most people think it's [common assumption], but that's
usually not it. The real cause is [actual cause]."

[10-25s] SOLUTION:
"Here's what to do instead: [step 1], [step 2], [step 3]."
(Show each step visually as you say it.)

[25-30s] CTA:
"Try this and let me know how it goes — follow for more
[topic] tips."
```

### Listicle Script
```
[0-3s] HOOK:
"5 [things] that [outcome] — number 3 surprised me."

[3-50s] ITEMS (one every 5-8 seconds):
"Number 1: [item + 1 sentence why it matters]"
"Number 2: ..."
... through number 5

[50-60s] CTA:
"Which one are you going to try first? Comment below."
```

### Tutorial Script
```
[0-3s] HOOK:
Show the finished result. "This is what we're making today."

[3-8s] OVERVIEW:
"It's easier than it looks — here's how."

[8-50s] STEPS:
Step through each action with minimal narration —
let the visuals carry it. Use on-screen text for
key numbers/timings.

[50-60s] RESULT + CTA:
Show the final result again. "Save this for later."
```

### Myth-Busting Script
```
[0-3s] HOOK:
"Myth: [common belief]. Here's the truth."

[3-10s] THE MYTH:
Briefly state the myth and why people believe it.

[10-45s] THE TRUTH:
Explain what's actually true, with evidence or example.

[45-60s] CTA:
"Did you believe this too? Let me know."
```

## Pacing Guidance by Length

| Length | Best For | Pacing Notes |
|---|---|---|
| 15-20 sec | Single idea, quick tip, trend participation | One beat every 3-5 sec, no wasted frames |
| 30-45 sec | Problem-solution, short tutorial | Allow 1-2 sec per step, hook must be instant |
| 60-90 sec | Story arc, multi-step tutorial, listicle | Can afford a brief setup (3-5 sec) before the core hook lands |

## On-Screen Text Rules

- Max 2 lines visible at once, 3-5 words per line
- Sync text changes to speech — don't let text linger past its spoken moment
- Use a consistent font/position so viewers' eyes know where to look
- Highlight the single most important word per line in a contrasting color

## Audio Notes

- Clear voice audio matters more than music — prioritize a decent mic
- Trending sounds can boost discovery, but only use them if they fit the content naturally
- Leave 0.5-1 sec of "breathing room" at the very start before speech begins, so the visual hook registers first
